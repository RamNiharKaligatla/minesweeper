# MERN Minesweeper

A full-stack Minesweeper game built using the MERN stack with recursive flood-fill logic, multiple difficulty modes, timer tracking, flagging mechanics, and persistent leaderboard storage using MongoDB.

---

## Features

- Dynamic Minesweeper board generation
- Recursive flood-fill reveal system
- Multiple difficulty modes
- Flagging system
- Win/loss detection
- Real-time timer
- Persistent leaderboard using MongoDB Atlas
- REST API integration
- Full-stack MERN architecture

---

## Tech Stack

### Frontend
- React

- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
